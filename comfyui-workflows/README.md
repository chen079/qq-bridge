# ComfyUI 工作流

把 ComfyUI 里「工作流 → 导出 (API)」得到的 JSON 放在这里，就能在控制台「AI 画图」页的下拉框里选择。
也可以直接在控制台里粘贴 / 上传导入。

文本里可用的占位符（整个值就是占位符时会保留数字类型）：

| 占位符 | 替换为 |
| --- | --- |
| `{{prompt}}` | 用户在 QQ 里写的提示词（含控制台设置的前缀） |
| `{{negative}}` | 控制台设置的反向提示词 |
| `{{seed}}` | 每次随机的种子（没写时会自动随机化所有 `seed` / `noise_seed`） |
| `{{width}}` / `{{height}}` | 控制台设置的宽高 |
| `{{checkpoint}}` | 控制台里选的模型（未选则用 ComfyUI 的第一个） |

没写 `{{prompt}}` 时，会自动把采样器 `positive` 输入所连的文本节点替换成提示词。
工作流必须有 SaveImage 节点，生成的图片才会发回 QQ。

## AI 主动画图（qq_draw_image）

除了群友发「画图 <提示词>」，二代模式（reserved2）与管理员私聊里的 AI 也可以自己调用 `qq_draw_image` 画图并发到会话，用的是同一个 ComfyUI 和同一套工作流。

- **只在 ComfyUI 连得上时注入**：QQ MCP 每 30 秒探一次 `/system_stats`，在线才把工具交给模型，掉线（连续两次探不到）就收回；开 ComfyUI 后不用重启 DSH。
- 开关：控制台「二代工具」里的 `qq_draw_image`（`socialV2.tools.drawImage`，默认开）。关掉后 30 秒内收回；若 DSH 启动时它就是关的，再打开需要重启 DSH（与其它工具开关一样）。
- 在哪能画沿用本页设置：画图群列表、聊天白名单；开启「仅管理员可用」或该会话规则为白名单时，AI 只能在管理员私聊里画（AI 代画分不清是谁要的）。
- 与群友指令共用「全局队列上限」；冷却按会话单独计算；计入二代发送频率上限。失败时模型只拿到固定原因，原始报错写在桥接日志里。
